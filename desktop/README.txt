CISTERCIAN CLOCK 1.1.0 - WINDOWS DESKTOP WIDGET

GET STARTED
Extract the ZIP to a writable folder, then open CistercianClock.exe.
Windows 10 and 11 with .NET Framework 4.x. No installer or administrator
access is required. This executable is unsigned; see DOWNLOAD TRUST below.

NEW IN 1.1
- Drag any edge or corner to resize; symbols preserve their proportions.
- A green cog in the lower-right corner opens a visible settings panel.
- Change whole-window transparency, or remove the background entirely.
- Choose a hidden date, Cistercian date, standard date text, or both.
- Choose day/month/year, month/day/year, year-month-day or a long date.

CONTROLS
Drag the clock to move it. With a transparent background, drag a symbol
to move and use the lower-right resize grip to resize.
Click the green cog, right-click, double-click or press S for settings.
F1 opens help. Esc hides to the tray; double-click the tray icon to restore.
Ctrl+Q quits. In the settings panel, Esc closes settings.

READING
Hours / minutes / seconds appear left to right in 24-hour time.
An empty stem means zero. The optional date follows your selected order;
long dates use day/month/year for the symbols.

SETTINGS
Four themes: Phosphor green, Amber, Ice and Paper.
Free resizing, pixel dimensions and Small/Medium/Large presets.
Whole-window transparency: 0-60% (keeps controls visible).
Transparent background: floating symbols, cog and corner grip.
Date display and format, seconds, decimal labels, glow, scanlines,
always on top, and device/London/UTC time zones.
Changes and position save beside the app in CistercianClock.settings.
A read-only folder prevents settings persistence. No network is used.

UPGRADING
Close the old widget, then replace its EXE with this version while keeping
CistercianClock.settings. Older settings files are read automatically.

DOWNLOAD TRUST
This app is not signed with a trusted publisher certificate. Chrome or
Windows may warn about an unsigned or unfamiliar download. The exact cause
of the earlier reported warning has not been confirmed. Do not disable
security protection or add exclusions. If a warning names a malware threat,
stop and record the exact message and file hash.
Checksums confirm file identity; they are not a safety certification.
