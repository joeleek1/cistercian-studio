CISTERCIAN CLOCK 1.0 - WINDOWS DESKTOP WIDGET

GET STARTED
Extract the ZIP to a folder you can write to, then double-click
CistercianClock.exe. No installer, administrator access, or internet
connection is required. Designed for Windows 10 and 11 with the built-in
.NET Framework 4.x. This is an unsigned community-built application.

READING THE CLOCK
Three symbols, from left to right: HOURS / MINUTES / SECONDS (24-hour time).
The default Phosphor theme is green on black with no decimal numbers or
labels. Each symbol combines up to four places around one central stem.
An empty stem is zero.

If you turn on the date, the lower row is DAY / MONTH / YEAR.
The clock uses your device's time. Choose local time, London or UTC;
London follows British Summer Time automatically.

CONTROLS
Drag anywhere on the clock to move it.
Right-click, double-click or press S to open the settings menu.
F1 opens this quick guide.
Esc hides the clock to the system tray.
Double-click its tray icon to bring it back.
Ctrl+Q quits. You can also choose Quit in the menu.

SETTINGS
Themes: Phosphor (green), Amber, Ice, Paper.
Sizes: Small, Medium, Large.
Opacity: 100%, 85%, 70%, 55%, 40%.
Toggle seconds, date, decimal labels, glow, CRT scanlines, and always on top.

Your choices and window position are saved in CistercianClock.settings
beside the executable. In a read-only folder they work for the current
session but cannot be saved. No personal information is collected.
It does not add itself to startup or change any system settings.

SOURCE AND BUILD
Source: https://github.com/joeleek1/cistercian-studio
Run desktop/build.ps1 from a PowerShell terminal to build from source.
The original numeral forms follow the supplied Cistercian chart. The
zero stem and grouping above 9,999 are app conventions.
